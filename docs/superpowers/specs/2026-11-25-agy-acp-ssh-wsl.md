# Antigravity ACP for SSH and WSL
Reuse upstream's AGY-over-ACP Claude transport, not the unreleased preview's separate kernel or any Google API relay. Both SSH and WSL already use the Bao remote server, whose authenticated process and file channels carry ACP and transcript writes. Google login and native AGY sessions remain with the user in the target environment. Expose host-scoped models and never fall back to the Windows account. Keep bot exclusions. Keep upstream main clean and publish a branch-specific Windows installer that does not auto-update to an official build. Preserve old preview data without claiming automatic transcript conversion.
